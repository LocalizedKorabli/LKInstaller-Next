## 概要

**澪刻 Next**（以下「**LK Next**」）は、[LK I18n Installer](https://github.com/LocalizedKorabli/I18nInstallerGUI)を完全に再構築したものです。

<details><summary style="font-size: 12px;">LK Next の新機能</summary>
<h4>以前のインストーラーと比較して LK Next に導入された新機能：</h4>

- 複数言語のローカライゼーションパッケージのインストールに対応：簡体字中国語、繁体字中国語、英語、日本語；
- Steam 上の Mir Korabley クライアントへのローカライゼーションパッケージのインストールに対応；
- ローカライゼーションパッケージのアンインストールに対応；
- フォント最適化パックのインストールに対応。ローカライズ言語が簡体字中国語/繁体字中国語/日本語に設定されている場合、このオプションはデフォルトで有効になります；
- アプリケーション自体のワンクリック更新に対応；
- 「**インスタンス**」と「**プリセット**」を導入し、複数のゲームクライアントインスタンスに対して異なるインストール/アンインストール操作を同時に実行できるようになりました；
- 優先順位付けによる複数の**ダウンロードルート**の同時使用に対応；
  - 対応ルート：
    - Tencent （フォント最適化とアプリ更新のみ）
    - Cloudflare （フォント最適化とアプリ更新のみ）
    - Gitee （ローカライズと EE パックのみ）
    - GitLab （ローカライズと EE パックのみ）
    - GitHub （ローカライズと EE パックのみ）
- より詳細なプロキシ設定が可能；
- アプリケーションインターフェース言語とライト/ダークテーマの切り替えに対応。

<h4>以前のインストーラーと比較した LK Next の機能変更：</h4>

- バージョン認識メカニズムが最適化され、リモートリポジトリで定義されたアクティブなバージョンにのみローカライゼーションパッケージがインストールされるようになりました；
- すべてのコンテンツが Mir Korabley で導入された .mkmod 形式でインストールされるようになりました；
- **L10n MOD**（旧漢化修改包）は、Mir Korabley で導入された「MO マウント」メカニズムを使用して常にインストールされるようになりました。

<h4>以前のインストーラーと比較して LK Next で削除された機能：</h4>

- 使用頻度が低くユーザーを誤解させる可能性があるため、グローバルサーバー/中国サーバーへのローカライゼーションパッケージのインストール機能は削除されました。

</details>

## LK Next のダウンロードとインストール

### ダウンロードルート
- [公式ダウンロードページ](https://localizedkorabli.org/ja/lk-next.html)

<details><summary style="font-size: 12px;"><b>ブラウザがダウンロードをブロックする場合の対処法</b></summary>

- Microsoft Edge （ lki_setup.exe は一般的にダウンロードされません。開く前にファイルを信頼できることを確認してください）：
  - ダウンロード項目にカーソルを合わせ、右側の「3 点」（...）アイコンをクリックし、**保持する**をクリックします；
  - 「lki_setup.exe を開く前に信頼できることを確認してください」ポップアップで、青い**削除**ボタンの横にあるドロップダウンメニューを開き、**とにかく保持**をクリックします。

- Chrome （不審なダウンロードがブロックされました）：
  - ダウンロード項目をクリックし、**不審なファイルをダウンロード**オプションをクリックします。

</details>

### アプリケーションのインストール
- ダウンロードしたインストーラーを開き、インストール言語を選択し（この言語は LK Next のデフォルト表示言語およびローカライゼーションパッケージのデフォルト言語としても設定されます）、指示に従ってインストールを完了します。

## LK Next の使い方

### 要約

追加設定なしでローカライゼーションパッケージのみをインストールする必要がある場合は、メインインターフェース（**ゲーム**タブ）の左下にある**インストール**ボタンをクリックするだけです。

### インスタンス

#### インスタンスとは？

インストールされた Mir Korabley クライアントは、ローカライゼーションパッケージをインストールするための「インスタンス」としてアプリケーションにインポートできます。

#### インスタンスのインポート

初回起動時に、アプリケーションはデバイス上のすべての Mir Korabley クライアントをスキャンし、インスタンスとしてインポートしようとします。

目的のインスタンスがリストに表示されない場合は、まずゲームが完全にインストールされていることを確認し、「ゲームインスタンス」ラベル行の右端にある**この PC のインスタンスを自動インポート**ボタンをクリックしてください。

それでもインポートされない場合は、同じラベル行の**インスタンスをインポート**ボタンをクリックして、手動でゲームインスタンスをインポートしてみてください。

#### インスタンスの管理

**ゲーム**タブで、現在インポートされているすべてのゲームインスタンスを表示できます。

また、**ゲーム**タブの他のボタンを使用して、インスタンスのインポート、クイック編集、削除、並べ替え、ディレクトリを開く、ゲームの実行、**自動更新ショートカットの作成**などを行うことができます。

#### インスタンスの選択（詳細情報の表示用）

ゲームインスタンスの名前をクリックして選択します。選択されると、インスタンス項目が青色でハイライトされます。**詳細**タブに切り替えると、インスタンスと現在選択されているプリセットの詳細情報を表示できます。

#### インスタンスのチェック（インストール/アンインストール用）

**ゲーム**タブでゲームインスタンスリスト項目の左側にあるチェックボックスをクリックして、インスタンスをチェック/チェック解除します。「ゲームインスタンス」ラベル行のチェックボックスをクリックすると、すべてのインスタンスを一度にチェック/チェック解除できます。

新しくインポートされたすべてのインスタンスはデフォルトでチェックされています。

### プリセット

#### プリセットとは？

インスタンスには複数の「プリセット」を持たせることができ、プリセットは**そのインスタンスにローカライゼーションパッケージをインストールする際にアプリケーションが実行する具体的な操作**を決定します：

- どの**言語/クライアントタイプ**（ Mir Korabley ライブ/PT ）のローカライゼーションパッケージをダウンロードしてインストールするか。
- [**EE パック**](#ee-パック)をダウンロードしてインストールするかどうか。
- [**フォント最適化**](#フォント最適化)をダウンロードしてインストールするかどうか。
- [**L10n MOD**](#l10n-mod) を読み込むかどうか。

#### デフォルトプリセット

すべてのインスタンスには**デフォルトプリセット**があり、インストール言語はデフォルトで**ユーザーがインスタンスをインポートしたときにアプリケーションが表示している言語**に設定されます。

#### プリセットの管理

プリセットを管理するには、まずゲームインスタンスを選択し、**詳細**タブに切り替えます。

「プリセット設定」フレームの**インストールプリセット**というドロップダウンメニューで、インスタンスのプリセットをすばやく切り替えることができます。

ドロップダウンメニューの右側にある歯車ボタンをクリックすると、**プリセットの管理**インターフェースが開きます。

プリセット管理インターフェースでは、次のことができます：
- インスタンスのプリセットの追加、削除、変更；
- プリセットのさまざまな設定の変更；
- 現在のプリセットの**自動更新ショートカットの作成**。

### カスタマイズ

#### EE パック

EE パックは、Mir Korabley 用の Mod セットで、以下が含まれます：
- [入力方式サポートMod](https://bbs.nga.cn/read.php?tid=29102783)；
- Unbound フレームワークに基づく UI 最適化 Mod ；
- 現在のローカライズ言語に基づく他の Mir Korabley Mod の翻訳パッチ Mod ；
- チームのブランディングを施した起動ロゴパッチ。

EE パックはデフォルトでインストールされます。**プリセットの管理**インターフェースでインストールするかどうかを選択できます。

#### フォント最適化

フォント最適化パックには、Mir Korabley 用のフォント最適化 Mod が含まれており、Mir Korabley のネイティブフォント「ALS Wagon」と「Source Han Sans CN」をベースにした新しいフォント「SrcWagon」が含まれています。一部のグリフの外観と位置が修正されています。

プリセットのローカライズ言語が**簡体字中国語**、**繁体字中国語**、または**日本語**に設定されている場合、フォント最適化パックがデフォルトでインストールされます。**プリセットの管理**インターフェースでインストールするかどうかを選択できます。

#### L10n MOD

L10n MOD は、ローカライゼーションパッケージ内の特定のテキストを変更するために使用されます。L10n MOD の作成については、[Mir Korabley フォーラムの投稿](https://forum.korabli.su/topic/162025-)を参照してください。

作成した L10n MOD を直接ドラッグ＆ドロップするか、zip ファイルにパッケージ化して、現在のプリセットの L10n MOD フォルダ（**プリセットの管理**インターフェースのフォルダアイコンボタンをクリックして開く）に配置できます。

L10n MOD は、**次回**ローカライゼーションパッケージをインストールするときに読み込まれます。

L10n MOD はデフォルトでインストールされます。**プリセットの管理**インターフェースでインストールするかどうかを選択できます。

### アプリ設定

**設定**タブでは、次のことができます：
- **外観**、**ダウンロード**、**ファイル**の設定を調整する；
- ダウンロードキャッシュと出力ログを消去する；
- アプリケーションのデータディレクトリを表示する。

### アプリ情報 / アプリの更新

**概要**タブでは、次のことができます：
- アプリケーションのバージョンを確認し、**アップデートのチェック**を行う；
- GitHub、QQ、Discord のアイコンをクリックして、ソースコードリポジトリにアクセスしたり、各ソーシャルプラットフォームのチームグループに参加したりする；
- 著作権表示の上にある紫色の「AGPL V3」アイコンをクリックして、GNU の公式 Web ページに移動し、本アプリケーションのライセンス全文を表示する。

## Q&A

### アプリがエラーを報告したり、ローカライゼーションパッケージのインストールに失敗した場合は？

まず[**アップデートのチェック**](#アプリ情報--アプリの更新)を試してから、ローカライゼーションパッケージを再インストールしてください。

**設定**タブに移動し、**データパス**行の**開く**ボタンをクリックします。開いたフォルダで、logs フォルダに入り、最新の .log ファイルを保存します。

このファイルを開いてエラーの原因を分析して自分で修正するか、ファイルを[GitHub Issues](https://github.com/LocalizedKorabli/LKInstaller-Next/issues) | [QQグループ](https://qm.qq.com/q/SUoZAcV442) | [Discordサーバー](https://discord.gg/3d9k2mkWy4)に提出してヘルプを求めることができます。

### 自動更新機能はどこに行きましたか？

[インスタンスの管理](#インスタンスの管理)と[プリセットの管理](#プリセットの管理)を参照してください。**ゲーム**タブまたは**プリセットの管理**インターフェースでインスタンスの**自動更新ショートカット**を作成できます。

### ローカライゼーションパッケージ自体について質問がある場合は？

使用している言語とクライアントタイプに応じて、[チームポータル](https://github.com/LocalizedKorabli#%E9%A0%85%E7%9B%AE%E4%BC%9D%E9%80%81%E9%97%A8portal)で関連するリポジトリを見つけ、その Issues でフィードバックを送信してください。

QQ グループや Discord サーバーに参加してディスカッションに参加することもできます。
